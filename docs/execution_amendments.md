# Execution amendments

A post-specification exploratory temporal sensitivity was added to separate baseline/prevalence transport from changes in conditional associations. For each verified temporal outcome, R8 and R10 observations from the same 30 countries are pooled with country-by-wave fixed intercepts and eight core-variable-by-wave interactions. Country-cluster sandwich intervals use t(29) and equal mass per country-wave. This is not a new confirmatory test, does not identify individual changes, and retains the logit-scale comparability qualification. All eight interactions per outcome are reported without significance-based selection.

During review, the occupation sensitivity coding was corrected to retain all harmonized nominal codes and to represent missing occupation as a separate category. A provisional transformation had grouped high codes and inadvertently pooled missing values with that group. Only occupation-adjusted fixed-effect sensitivity estimates use this field; the eight-variable primary models and predictions do not. The sensitivity was rerun and the correction is retained in the code and source dictionary.

After all 28 explanatory fits were completed, prediction initially failed because glmmTMB required the named likelihood-weight variable in its new-data frame. The prediction interface now supplies a constant dummy weight solely for model-frame reconstruction; these values do not enter predictions or evaluation weights. Known- and unseen-country prediction calls were verified from a saved model before restarting prediction-only execution. Completed explanatory models were retained. Predictive core fits use glmmTMB fixed-coefficient profiling for numerical efficiency, preserving the same Laplace objective. A full-sample numerical comparison with lme4 nAGQ=0 differed by less than 0.0002 in conditional probabilities; that approximate estimator was not substituted for the primary prediction engine.

The scaled lme4 adjusted-model attempts remained computationally slow and were stopped, retaining their logs and completed null outputs. Adjusted, slope, moderation and predictive models were switched to the established glmmTMB automatic-differentiation Laplace implementation. A full cultural within–between comparison converged with a positive-definite Hessian before adoption. Null models retain lme4 nine-point adaptive quadrature and are independently refitted with glmmTMB Laplace as an approximation check. No completed higher-quadrature adjusted-model sensitivity is claimed. Likelihood constants differ between implementations for fractional weights; raw likelihood/AIC values are not compared across engines. A diagnostic extraction failure caused by an absent gradient in the lme4 optimizer object was repaired; the failed attempt produced no adjusted-model results.

22 November 2026: the first mixed-model run completed the four null models, but the unscaled within–between fits were computationally slow. Between-country female proportions have very small dispersion relative to the other columns. Before using any within–between coefficient result, national-mean predictors were rescaled by their country-level standard deviation and optimization switched from bobyqa to nloptwrap. This is a nonsubstantive reparameterization; within-country coefficients remain in the declared original units, and between-country coefficients are now per one SD of country means. Scaling factors are saved by outcome. Original null outputs and first-attempt logs are archived separately; no attempted run is concealed. No outcome or model term was selected using statistical significance.
